# Setline

Setline is an iPhone-first training log for experienced lifters who plan their own workouts. This stage builds the interface around a clearly labeled sample training week.

## Open the preview

Run `npm run dev` from this folder, then open [the local preview](http://127.0.0.1:4173/). The preview uses Node.js and has no package dependencies.

On a Mac with Xcode 16 or later, open `ios/Setline.xcodeproj`, select the **Setline** scheme and an iPhone simulator, then run. The deployment target is iOS 17. Windows supports the browser preview. Building and running the native app requires Xcode.

See the [project brief](PROJECT_BRIEF.md) for the stage scope, data conventions, verification, and remaining work.
